
# 🔐 Linux Secrets Manager

A simple command-line based Secrets Manager built using **Bash scripting on Linux**.

This project demonstrates basic Linux command-line operations, Bash scripting, file handling, user authentication, input validation, and conditional statements.

## 📌 Features

- 👤 New user registration
- 🔑 Username and password authentication
- 📁 Automatic creation of database files
- 🔍 Duplicate username validation
- 🔒 Hidden password input
- ✅ Login authentication
- ⚠️ Input validation
- 🖥️ Interactive command-line menu
- 📄 File-based user data storage

## 🛠️ Technologies Used

- Linux
- Bash
- Shell Scripting
- grep
- File Handling
