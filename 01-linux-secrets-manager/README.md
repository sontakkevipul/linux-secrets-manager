# 🔐 Linux Secrets Manager

A command-line based Secrets Manager built using Bash scripting on Linux.

## Features

- User registration
- User authentication
- Password handling
- Input validation
- File-based data handling
- Interactive command-line interface

## Technologies

- Linux
- Bash
- Shell Scripting
- grep
- File Handling

## How to Run

```bash
chmod +x secrets_manager.sh
./secrets_manager.sh
