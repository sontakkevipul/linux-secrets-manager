# 🔐 Linux Secrets Manager

A command-line based Secrets Manager built using **Bash scripting on Linux**.

This project demonstrates practical Linux and Shell Scripting concepts including
user authentication, file handling, input validation, conditional logic,
and command-line operations.

---

## 📌 Features

- 👤 User registration
- 🔑 Username and password authentication
- 🔒 Hidden password input
- 🔍 Duplicate username validation
- 📁 File-based data storage
- ✅ Input validation
- 🖥️ Interactive command-line interface
- ⚠️ Invalid input handling

---

## 🛠️ Technologies Used

- Linux
- Bash
- Shell Scripting
- grep
- File Handling
- Command-Line Utilities
